Cloud-first architecture

Saved data goes to the cloud. The browser may hold only temporary in-memory state or a short-lived cache.

01

Cloudflare Pages

Hosts the responsive React/TypeScript PWA and marketing pages.

02

Cloudflare Workers

Always-reachable API boundary, signed storage URLs, rate limits, webhooks, AI consent, and admin aggregates.

03

Supabase

Auth and PostgreSQL for profiles, settings, roles, subscriptions, feature flags, sync metadata, and audit logs.

04

Cloudflare R2

Encrypted monthly journal chunks, attachments, snapshots, and recovery manifests.

05

External providers

Broker, market data, payment, email, calendar, AI, and monitoring adapters remain replaceable.

06

Security boundary

Private data is encrypted before upload; service secrets never enter browser code.

Admin control system

Admin controls are backend-enforced and never trusted to browser UI alone.

User login → Supabase Auth session → Worker verifies JWT → role claim checked
                                                        ↓
Normal user → /dashboard, /journal, /analysis, /settings
Admin user  → same user routes + protected /admin routes
                                                        ↓
Admin changes feature flag → audit event → entitlement cache → user sees updated access

Admin never receives:
  private journal plaintext · psychology · screenshots · broker secrets · recovery keys
